# 从零安装与真实接入

## 1. 环境与演示

准备 Python 3.11+；完整平台接入另需 Windows、Google Chrome 和 Node.js 20.18.1+。终端切换到解压后的项目目录：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe finintel.py --demo
```

打开终端给出的地址，BOSS 输入 `消费金融 产品经理`。应看到标有演示来源的任务、整理结果和原文引用。合成材料用于体验工作流。演示模式不使用自己的 BOSS 账号，不会让 X/小红书变成演示来源。按 Ctrl+C 停止服务。

## 2. 安装真实平台依赖

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-platforms.txt
npm install --prefix "$env:USERPROFILE\.opencli" @jackwener/opencli@1.8.8
.\.venv\Scripts\python.exe scripts/repair_xhs_search_visibility.py
.\.venv\Scripts\python.exe finintel.py
```

X/小红书的浏览器通道需要安装 [OpenCLI Chrome 扩展](https://chromewebstore.google.com/detail/opencli/ildkmabpimmkaediidaifkhjpohdnifk)，按 [OpenCLI 项目说明](https://github.com/jackwener/opencli) 连接自己控制的 Chrome 会话。保留正常 Chrome，登录 X 和小红书。检查连接：

```powershell
node "$env:USERPROFILE\.opencli\node_modules\@jackwener\opencli\dist\src\main.js" doctor
```

应用会优先解析独立 `.opencli` 安装，也能在高级设置里指定工具路径。小红书修复脚本只针对已验证的搜索可见性函数；生成备份，可重复运行；版本结构不匹配时拒绝修改。

## 3. 配置模型

打开设置，填写 OpenAI 兼容 API 的 base URL、模型名和自己的 API key，保存并测试。未配置模型时，真实研究会提示无法整理；已取得材料保留。密钥不会回显或写入报告，但存于本机 SQLite 设置中，数据库按私密文件保护。

## 4. BOSS：使用专用窗口

在首页/设置点击“登录 BOSS”，应用打开专用 Chrome。也可双击 `open-collect-browser.bat`。在这个窗口里本人扫码/登录；出现验证时本人完成。回到应用确认或刷新连接状态，输入关键词，再点击“搜索并整理”。

专用窗口与平时 Chrome 是不同的账号存储；在普通 Chrome 登录不能替代专用窗口的登录。应用冻结每个任务的采集通道，并验证本机端口与浏览器标识，搜索、详情都沿用这一会话。保持窗口开启。

结果中“完整正文”指已验证详情页中可见、未裁剪的职位描述区；并非网页所有模块。卡片、裁剪正文、失配 URL 不会升级成完整。主流程最多两页搜索和二十次详情调用，失败调用也计入预算；搜索总数可能大于成功读取数。

## 5. X 与小红书

在首页切换来源，分别输入关键词并搜索。X 可在设置中配置自己的凭据；浏览器搜索通道使用已登录 Chrome。Twitter CLI 遇到特定连接或契约错误时最多尝试一次 OpenCLI 关键词搜索；登录失效、限流和风控不会触发切换。

小红书会分别保存笔记与本批读取到的评论。点开某条结论的证据，检查来源、原文和上下文。连接成功与已经取得真实数据是两种状态；首次真实搜索完成后才有本次取数证明。

## 6. 中断与恢复

平台登录/验证/风控会停止采集，保留已完成快照。详情页的验证窗口保留给本人操作，不代过验证码。完成后按界面提供的恢复入口继续；预算不会清零。环境风险按平台提示处理，未解除前不要重复请求。仅“重新整理”只处理已有材料，不重搜平台。“获取最新结果”在搜索预算用完时创建新批次，历史结果保留。

若端口冲突，用 `finintel.py --port 8780`，并打开对应地址。高级配置见设置页；不要复制别人 `.local`、Cookie、简历或数据库来修复自己的安装。

## 7. 目录与退出

本机状态在 `.local/`，报告在 `outputs/`；日志与进程证明在 `.local/run/`。按 Ctrl+C 退出服务。浏览器登录数据保留，下次可继续使用。删除项目私有数据前先导出自己需要的报告。不要公开这些目录；公开发布使用源代码白名单打包脚本。

## 从研究到面试准备

1. 搜索 BOSS 岗位，在“岗位明细”中选择“准备此岗位”（或展开方向卡中的岗位入口）。应用保存的是该次搜索的 JD 快照，不会替换为岗位后来的版本；部分正文会提示覆盖不足。
2. 在“面试准备工作区”选择已有 X／小红书搜索的结论；也可以去相应来源搜索，再点击“加入面试准备”选择该会话。每次加入的是结论的原文证据（最多三条），总共最多八条；重复加入不会重复计数。
3. 导入或选择自己的简历，校对条目。点击“匹配矩阵”中的“用 AI 分析”，得到仅基于 JD 与简历的匹配结果。
4. 在“面试重点”生成准备计划。所选公开讨论以单独的“公开讨论背景练习”呈现，每条都保留原文引用、与岗位的联系和不确定性。它不是招聘方真实面试题，也不是个人工作经历。
5. 到“准备清单”跟踪完成状态，导出 MD 报告；报告包含 JD／简历依据与背景来源。
6. 更换 JD、简历需重新匹配；加入或移除背景材料需重新生成准备计划。旧计划不会悄悄伪装成最新版本，页面和报告会标明过期。

背景材料可不选。正常模式需要配置真实模型，不会因模型错误改用规则；显式演示模式在未配置模型时使用合成材料与规则，结果会明确标注。
